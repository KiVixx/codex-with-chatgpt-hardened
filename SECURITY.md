# Security Policy

This fork is intended for local development with a read-only remote planning
connection. Please do not disclose credentials, tokens, private keys, or
pairing codes in bug reports.

## Reporting a vulnerability

Open a private GitHub security advisory on the fork when available. Otherwise
contact the repository owner privately with a minimal reproduction, affected
commit, and impact. Do not publish exploit details before a fix is available.

## Supported versions

The `main` branch and the latest tagged hardened release are supported. Keep
the bridge and Skill from the same reviewed commit.
